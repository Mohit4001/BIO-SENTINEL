## 💡 About the Project

BIO SENTINEL is an AI-powered wearable system designed to provide continuous, personalized health monitoring and early risk detection.

Unlike conventional wearables that mainly display health parameters, BIO SENTINEL combines:

- Physiological data
- Activity data
- Environmental data
- Personal baseline
- On-device TinyML
- Disaster-aware context

to generate a **Personal Risk Score** and take appropriate action.
